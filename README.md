# 📦 极粹工具 (Essence Tools)

[![GitHub Repo](https://img.shields.io/badge/github-cori--168%2Fessence--tools-blue?logo=github&style=flat-square)](https://github.com/cori-168/essence-tools)


基于 **Next.js 15 (App Router)** + **React 19** 构建的全栈在线工具平台。
前台内置多款强大、纯前端运行的实用工具（数据不离开浏览器，充分保障隐私），后台提供了一套完整的 **用户账户体系、积分签到系统与管理后台**。

## 🚀 技术栈

- **前端框架**：Next.js 15 (App Router) + Turbopack, React 19
- **样式方案**：Tailwind CSS v4
- **组件库与图标**：Lucide React
- **核心依赖**：TipTap (富文本编辑器), Marked (Markdown 解析), DiceBear (头像生成)
- **数据库与 ORM**：Prisma + SQLite (支持平滑迁移至 PostgreSQL)
- **认证与安全**：JWT (jose), bcryptjs, HttpOnly Cookie
- **邮件服务**：nodemailer (支持 SMTP 验证、密码找回)

## 🛠️ 工具特性详解

### 1. 📖 小说排版器

专为网文写手与编辑打造的终极排版工具，能一键将混乱的 TXT 文本规范为符合中文阅读标准的排版格式。

- **29 条规则，4 阶段管线化处理**：
  - **字符转换**：全角字母/数字转半角，统一间隔号。
  - **标点统一**：保护小数点、时间格式的前提下，中文化标点（自动推断并修复引号匹配、规范化省略号和破折号）。
  - **空格处理**：中英文间隙自动增加空格（pangu）、数字与单位间距修复。
  - **段落与行级**：合并多余空行、首行自动缩进、标题识别、防盗版乱码过滤。
- **实时高亮与同步滚动**：左右面板按阅读比例精准同步滚动，悬停段落双向高亮对照。

### 2. 📝 HTML 编辑器

重构至现代化的 **TipTap** 引擎，带来极致流畅的书写体验。

- **全功能格式支持**：支持各类文字格式、对齐方式、有序/无序列表。
- **图片与表格控制**：支持插入图片（支持拖拽缩放、对齐设定），支持右键呼出菜单增删表格行/列。
- **双模态编辑**：支持所见即所得的可视化编辑，与 HTML 源码编辑自由切换，内置源码美化功能。
- **安全与稳定性**：本地自动防抖保存（localStorage），页面刷新不丢数据；智能清洗粘贴来源的 XSS 攻击标签。

### 3. 📄 Markdown 编辑器

为极客量身定制的轻量级 Markdown 写作工具。

- **沉浸式分屏**：全新加入无极调节拖拽把手，在编辑区和预览区之间自由拖拽划分屏幕。
- **实时渲染**：接入 Marked 并通过 DOMPurify 进行安全消杀，代码块自带 GitHub 风格的高亮。
- **快捷工具栏**：支持一键插入粗体、引用、链接、代码块，提供便捷的全局查找/替换悬浮条。

### 4. 🎲 头像生成器

- 多种艺术风格切换（Notion 风格、玻璃拟物、像素艺术等）。
- “来点灵感”一键使用内置语录库生成专属种子。
- 支持调整头像背景、导出高清晰度的 SVG 矢量图。

## 📦 本地开发与部署

1. **安装依赖**
   \`\`\`bash
   npm install
   \`\`\`

2. **初始化数据库**
   默认使用本地 SQLite 数据库：
   \`\`\`bash
   npx prisma db push
   npx prisma generate
   \`\`\`

3. **配置环境变量**
   复制并修改环境变量配置：
   \`\`\`bash
   cp .env.example .env
   \`\`\`

4. **启动开发服务器**
   \`\`\`bash
   npm run dev
   \`\`\`
   内置 Turbopack 引擎，启动速度极快。浏览器访问 \`http://localhost:3000\` 即可体验。

## 🔒 生产环境推荐

- 在生产环境下建议将 Prisma 配置（\`prisma/schema.prisma\`）中的 provider 从 \`sqlite\` 修改为 \`postgresql\`。
- 请务必在 \`.env\` 中修改强哈希的 \`JWT_SECRET\`。
